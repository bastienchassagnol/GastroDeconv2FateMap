# Pseudo-bulk generation strategies for phenotype-guided single-cell benchmarking

> **Shared notation**
>
> Let
>
> ``` math
> X^{\mathrm{sc}} = (x_{gc}) \in \mathbb{N}^{G \times C}
> ```
>
> be the single-cell count matrix, with genes $`g=1,\ldots,G`$ and cells
> $`c=1,\ldots,C`$.
>
> Each cell has metadata
>
> ``` math
> b(c) \in \{1,\ldots,B\}
> ```
>
> for barcode / organoid ID, and
>
> ``` math
> y_{b(c)} \in \{0,1\}
> ```
>
> for organoid-level phenotype, with $`y=1`$ denoting successful
> differentiation and $`y=0`$ denoting failed differentiation /
> neuroectodermal output.
>
> A pseudo-bulk sample $`i`$ is generated by selecting a set of cells
>
> ``` math
> \mathcal{C}_i \subseteq \{1,\ldots,C\}
> ```
>
> and aggregating their expression:
>
> ``` math
> Y_{gi}^{\mathrm{raw}} = \sum_{c \in \mathcal{C}_i} s_c x_{gc},
> ```
>
> where $`s_c`$ is an optional cell-level scaling factor, often
> $`s_c=1`$.
>
> The normalized pseudo-bulk profile can then be written as
>
> ``` math
> Y_{gi} = \mathrm{Norm}\left(Y_{gi}^{\mathrm{raw}}\right),
> ```
>
> for example library-size normalization, TPM/CPM, DESeq2 size-factor
> normalization, or log transformation.
>
> For cell-type-aware simulations, let $`z_c \in \{1,\ldots,K\}`$ be the
> cell type or state label, and let
>
> ``` math
> \pi_i = (\pi_{i1},\ldots,\pi_{iK}), \qquad \sum_{k=1}^K \pi_{ik}=1,
> ```
>
> be the target composition of pseudo-bulk sample $`i`$.

## Condensed comparison of pseudo-bulk generation strategies

| Strategy | Core idea | Sampling / generation equation | What is controlled? | What is realistic? | Main limitation | Recommended use for organoid phenotype benchmarking |
|----|----|----|----|----|----|----|
| **1. Direct organoid-barcode aggregation** | Treat each organoid barcode as one bulk sample. This is the closest pseudo-bulk analogue to an experimentally sequenced organoid bulk RNA-seq sample. | For organoid $`b`$: 
``` math
Y_{gb}^{\mathrm{raw}}=\sum_{c:b(c)=b}x_{gc}
```
 Then normalize: 
``` math
Y_{gb}=\log_2\left(1+\frac{10^6Y_{gb}^{\mathrm{raw}}}{\sum_gY_{gb}^{\mathrm{raw}}}\right)
```
 or use DESeq2 size factors. | Real organoid-level biological heterogeneity; barcode-specific cell composition; phenotype labels $`y_b`$. | Highest realism if each barcode corresponds to a true biological organoid. Preserves natural co-variation among cell states within organoids. | Limited number of bulk samples: e.g. only 8 organoids gives poor statistical power for the 8 phenotype-guided algorithms. | Use as the **primary benchmark** if enough organoids exist. With only 8 organoids, use it as a realism anchor and complement it with bootstrap simulations. |
| **2. Phenotype-stratified bootstrap pseudo-bulk** | Build many pseudo-bulk samples by resampling cells from organoids with the same phenotype. Similar to the scPP simulation logic, where phenotype-positive and phenotype-negative cells are sampled separately to create balanced pseudo-bulk cohorts. | For pseudo-bulk sample $`i`$ with phenotype $`y_i`$: 
``` math
\mathcal{C}_i \sim \mathrm{Sample}\{c:y_{b(c)}=y_i\}, \quad |\mathcal{C}_i|=N_i
```
``` math
Y_{gi}^{\mathrm{raw}}=\frac{1}{N_i}\sum_{c\in\mathcal{C}_i}x_{gc}
```
 or sum first, then normalize. | Number of pseudo-bulk samples; number of cells per pseudo-bulk; class balance; phenotype-specific signal strength. | Retains empirical single-cell distributions and dropout patterns. | Resampled pseudo-bulk samples are not independent biological replicates if drawn from the same few organoids. Can inflate apparent benchmark power. | Best practical option when bulk RNA-seq is missing. Generate, for example, 50–100 pseudo-bulk samples per phenotype, but report that biological independence is limited. |
| **3. Organoid-preserving bootstrap** | Resample within each barcode, then aggregate. This preserves organoid identity while creating technical pseudo-replicates. | For organoid $`b`$, replicate $`r`$: 
``` math
\mathcal{C}_{br}\sim \mathrm{Sample}\{c:b(c)=b\},\quad |\mathcal{C}_{br}|=N_{br}
```
``` math
Y_{gbr}^{\mathrm{raw}}=\sum_{c\in\mathcal{C}_{br}}x_{gc}
```
``` math
y_{br}=y_b
``` | Technical variability within organoids; sequencing-depth variation; cell sampling noise. | Preserves barcode-specific transcriptional and compositional structure. | Does not create new biological organoids; replicates are nested within barcode. | Good for stress-testing algorithms while avoiding total mixing across barcodes. Use mixed-effects evaluation: pseudo-bulk replicates nested within organoid. |
| **4. Composition-controlled Dirichlet convolution** | Draw target cell-state proportions from a Dirichlet distribution, then linearly mix empirical cell-type or state references. This mirrors the HADACA3-style convolution benchmark. | Draw composition: 
``` math
\pi_i \sim \mathrm{Dirichlet}(\alpha)
```
 Define cell-state reference means: 
``` math
\mu_{gk}=\frac{1}{|C_k|}\sum_{c:z_c=k}x_{gc}
```
 Generate: 
``` math
Y_{gi}=\sum_{k=1}^K \mu_{gk}\pi_{ik}+\varepsilon_{gi}
``` | Cell-state proportions; rare-cell scenarios; missing or extra cell types; controlled noise. | Very interpretable; known ground-truth proportions. | Reference-mean convolution can be too smooth and underestimates single-cell sampling noise unless noise is added. | Useful to isolate whether algorithms recover phenotype-associated states when the phenotype is encoded through known changes in $`\pi_i`$. |
| **5. Empirical cell sampling from target proportions** | Draw proportions $`\pi_i`$, then sample actual cells from each cell type/state according to $`\pi_i`$, rather than mixing mean references. | Draw: 
``` math
\pi_i \sim \mathrm{Dirichlet}(\alpha)
```
 Sample counts: 
``` math
(N_{i1},\ldots,N_{iK})\sim \mathrm{Multinomial}(N_i,\pi_i)
```
 Then: 
``` math
Y_{gi}^{\mathrm{raw}}=\sum_{k=1}^K\sum_{c\in\mathcal{C}_{ik}}x_{gc}
``` | Proportions, total number of cells, phenotype-composition coupling, rare states. | Preserves empirical dropout, overdispersion, and cell-to-cell heterogeneity better than reference-mean convolution. | Still assumes sampled cells can be recombined freely; may break organoid-level dependencies. | Strong default for in silico benchmarking of phenotype-guided algorithms when no real bulk exists. |
| **6. SimBu scenario-based pseudo-bulk** | Use predefined pseudo-bulk scenarios from SimBu. These aggregate scRNA-seq profiles under controlled cell-type fractions and optional mRNA-bias scaling. | Generic form: 
``` math
Y_{gi}^{\mathrm{raw}}=\sum_{c\in\mathcal{C}_i}s_cx_{gc}
```
 with $`\mathcal{C}_i`$ selected according to a scenario: `even`, `random`, `mirror_db`, `weighted`, `pure`, or `custom`. | Scenario-specific cell-type fractions; number of cells; number of samples; mRNA-content bias; whitelist / blacklist cell types. | Practical, standardized, reproducible; can mimic compositional shifts and mRNA bias. | Primarily designed for deconvolution benchmarking; phenotype labels must be added by the user. | Use `custom` or `weighted` to impose success/failure-associated organoid compositions. Use `mirror_db` to mimic your observed organoid composition. |
| **7. Mean pseudo-bulk with dropout correction / small epsilon** | Aggregate cells and stabilize zeros using a small offset before log-normalization. Similar to simple pseudo-bulk pipelines using [`Seurat::AggregateExpression`](https://satijalab.org/seurat/reference/AggregateExpression.html) followed by DESeq2-like normalization. | Aggregate: 
``` math
Y_{gi}^{\mathrm{raw}}=\sum_{c\in\mathcal{C}_i}x_{gc}
```
 Stabilize: 
``` math
\tilde{Y}_{gi}=\log_2(Y_{gi}^{\mathrm{raw}}+\epsilon)
```
 or normalize then add $`\epsilon`$. | Dropout sensitivity; zero handling; library-size normalization. | Simple and robust for sparse scRNA-seq. | Returns essentially mean/sum expression profiles; does not model covariance or GRN structure explicitly. | Use as a baseline pseudo-bulk generator. Good first-pass choice before complex generative models. |
| **8. Gaussian latent-factor / GGM-based simulation** | Infer a Gaussian or latent Gaussian model from single cells, then generate pseudo-bulk by summing simulated cells. Useful when modeling gene-gene covariance or GRN-like precision matrices. | For state $`k`$: 
``` math
z_c\mid z_c=k\sim\mathcal{N}(\mu_k,\Sigma_k), \qquad \Theta_k=\Sigma_k^{-1}
```
 Generate cells: 
``` math
x_c=z_c \quad \text{or} \quad x_c=\exp(z_c)
```
 Aggregate: 
``` math
Y_i=\sum_{c\in\mathcal{C}_i}x_c
``` | Gene-gene covariance; sparse precision matrix; latent programs; phenotype-specific GRN perturbations. | Can simulate coordinated gene programs rather than independent genes. | If $`x_c`$ is log-normal, $`\sum_c x_c`$ is not log-normal. Parameters inferred at single-cell level may not transfer cleanly to bulk. | Use for mechanistic stress tests, not as the only benchmark. Compare against empirical aggregation to avoid over-interpreting simulated GRNs. |
| **9. scDesign2-like copula / marginal-dependence simulation** | Model gene-wise marginals with count distributions and capture dependence using copulas. | Gene marginals: 
``` math
X_{gc}\sim F_g(\theta_g)
```
 Dependence: 
``` math
U_{gc}=F_g(X_{gc}),\qquad (U_{1c},\ldots,U_{Gc})\sim C_\rho
```
 Aggregate simulated cells: 
``` math
Y_{gi}^{\mathrm{raw}}=\sum_{c\in\mathcal{C}_i}X_{gc}^{\mathrm{sim}}
``` | Gene-wise count distribution; gene-gene dependency; overdispersion; zero inflation. | More realistic than independent gene simulation. | High-dimensional copula fitting is difficult; dependency estimates can be unstable for sparse scRNA-seq. | Use to test whether algorithms are robust to realistic gene-gene dependence without imposing a mechanistic GRN. |
| **10. Splatter / gllvm-style gene-level simulation** | Simulate genes using statistical count models without explicit GRNs. | Typical negative-binomial form: 
``` math
X_{gc}\sim \mathrm{NB}(\mu_{gc},\phi_g)
```
 with batch, group, library-size, and dropout effects. Aggregate simulated cells: 
``` math
Y_{gi}^{\mathrm{raw}}=\sum_{c\in\mathcal{C}_i}X_{gc}
``` | Library size; dropout; group effects; batch effects; gene-level overdispersion. | Good for technical noise stress tests. | Does not model regulatory network structure; phenotype signal must be imposed manually. | Useful negative-control simulator: ask whether algorithms falsely detect phenotype-associated cells when only technical effects differ. |
| **11. scMultiSim / GRN + cell-cell interaction simulation** | Generate single-cell profiles from explicit TF-based GRNs, cell-cell interactions, trajectories, batch effects, and technical noise. | Schematic form: 
``` math
h_c = f_{\mathrm{GRN}}(u_c, t_c, \mathrm{CCI}_c, \mathrm{batch}_c)
```
``` math
X_{gc}\sim \mathrm{CountModel}(h_{gc})
```
``` math
Y_{gi}^{\mathrm{raw}}=\sum_{c\in\mathcal{C}_i}X_{gc}
``` | GRNs, TF modules, trajectories, cell-cell interactions, technical noise, batch effects. | Mechanistically richer than pure count simulation. | More parameters; simulated mechanisms may not match organoid biology. | Useful to test whether phenotype-guided methods recover known causal programs or are merely detecting composition shifts. |
| **12. ODE / mechanistic differentiation simulator** | Simulate developmental trajectories mechanistically, then sample cells from success/failure attractors and aggregate. | Regulatory dynamics: 
``` math
\frac{dz_c(t)}{dt}=f(z_c(t),\theta,u_c)+\xi_c(t)
```
 Observed counts: 
``` math
X_{gc}\sim \mathrm{ObsModel}(z_{gc}(t_c))
```
 Bulk: 
``` math
Y_i=\sum_{c\in\mathcal{C}_i}X_c
``` | Differentiation dynamics; bifurcation; fate success/failure; time; perturbations. | Best aligned with gastruloid differentiation biology if the model is credible. | Requires strong mechanistic assumptions and parameter calibration. | Use for hypothesis-driven simulations after empirical pseudo-bulk benchmarks are established. |
| **13. DANST-style pseudo-domain alignment** | Generate pseudo-bulk or pseudo-spots from scRNA-seq, then align pseudo and real domains through adversarial training. Originally designed for pseudo-ST to real-ST alignment, but the idea transfers to pseudo-bulk vs real-like bulk alignment. | Pseudo profile: 
``` math
Y_i^{\mathrm{pseudo}}=\sum_{c\in\mathcal{C}_i}x_c
```
 Feature embedding: 
``` math
v_i=F_\theta(Y_i)
```
 Adversarial objective: 
``` math
\min_{F,P}\max_D \mathcal{L}_{\mathrm{pred}}(P(F(Y^{\mathrm{pseudo}})),\pi) - \lambda\mathcal{L}_{\mathrm{domain}}(D(F(Y)))
``` | Domain shift between simulated pseudo-bulk and target bulk-like data. | Learns representations less sensitive to platform or simulation artifacts. | Requires target-domain data or realistic unlabeled bulk-like profiles; more complex than direct aggregation. | Use when synthetic pseudo-bulk distributions differ strongly from real bulk expectations, or when combining multiple data sources. |

## SimBu scenarios: compact design guide

| SimBu scenario | Composition rule | Equation / sampling intuition | Use in your organoid benchmark |
|----|----|----|----|
| **`even`** | All cell types have equal fractions. | 
``` math
\pi_{ik}=1/K+\delta_{ik}
``` | Baseline control where phenotype should not be driven by composition unless expression programs differ. |
| **`random`** | Random fractions over all available cell types. | 
``` math
\pi_i \sim \mathrm{UniformSimplex}(K)
``` | Stress-test algorithms under broad compositional variability. |
| **`mirror_db`** | Simulated fractions mirror the observed cell-type composition in the source scRNA-seq dataset. | 
``` math
\pi_i \approx \hat{\pi}^{\mathrm{observed}}
``` | Good realism baseline for your 8 organoids if you want pseudo-bulk samples to resemble the observed atlas. |
| **`weighted`** | One selected cell type is over-represented at a specified fraction. | 
``` math
\pi_{ik^\star}=w,\qquad \sum_{k\neq k^\star}\pi_{ik}=1-w
``` | Encode success/failure by over-representing trunk-like or neuroectodermal states. |
| **`pure`** | Only one cell type is present. | 
``` math
\pi_{ik^\star}=1,\qquad \pi_{ik}=0 \; (k\neq k^\star)
``` | Positive control: algorithms should easily detect phenotype-linked marker programs. |
| **`custom`** | User supplies the full composition matrix. | 
``` math
\Pi = \begin{bmatrix} \pi_{11} & \cdots & \pi_{1K}\\ \vdots & & \vdots\\ \pi_{n1} & \cdots & \pi_{nK} \end{bmatrix}
``` | Best choice for gastruloids: explicitly define success/failure composition designs and replicate them across pseudo-bulk samples. |

## Suggested benchmark design for 8 barcoded organoids

> **Tip**
>
> For your specific setting — approximately 20,000 single cells from 8
> barcoded organoids, with four successful and four failed
> differentiation outcomes — avoid relying on a single pseudo-bulk
> design.
>
> A robust benchmark could use three nested levels:
>
> 1.  **Observed organoid pseudo-bulk**
>
>     ``` math
>     Y_b=\sum_{c:b(c)=b}x_c
>     ```
>
>     This gives $`8`$ realistic pseudo-bulk samples.
>
> 2.  **Organoid-preserving bootstraps**
>
>     ``` math
>     Y_{br}^{\mathrm{boot}}=\sum_{c\in\mathcal{C}_{br}}x_c,
>     \qquad
>     \mathcal{C}_{br}\subseteq\{c:b(c)=b\}
>     ```
>
>     This gives technical replicates while preserving barcode
>     structure.
>
> 3.  **Phenotype-stratified or custom-composition simulations**
>
>     ``` math
>     Y_i=\sum_{k=1}^K\sum_{c\in\mathcal{C}_{ik}}x_c,
>     \qquad
>     (N_{i1},\ldots,N_{iK})\sim\mathrm{Multinomial}(N_i,\pi_i)
>     ```
>
>     This creates controlled success/failure pseudo-bulk cohorts with
>     known ground truth.

## Main statistical caveat

If single-cell expression vectors are independent and Gaussian,

``` math
x_c\sim\mathcal{N}(\mu,\Sigma),
```

then aggregation is simple:

``` math
Y_i=\sum_{c=1}^{N_i}x_c \sim \mathcal{N}(N_i\mu,N_i\Sigma).
```

But if cells share organoid-level programs,

``` math
\mathrm{Cov}(x_c,x_{c'})=C \quad (c\neq c'),
```

then

``` math
\mathrm{Var}(Y_i) = N_i\Sigma + N_i(N_i-1)C.
```

The $`N_i(N_i-1)C`$ term means that shared biological programs can
dominate pseudo-bulk variance. Therefore, naïve aggregation can
overstate biological signal if many bootstraps reuse the same organoids.

For log-normal single-cell models,

``` math
x_c=\exp(z_c),\qquad z_c\sim\mathcal{N}(\mu,\Sigma),
```

the sum

``` math
Y_i=\sum_c x_c
```

is not exactly log-normal. Moment-matching or Gaussian CLT
approximations may be used, but the sparse precision matrix inferred at
the single-cell level is generally not preserved after aggregation.
