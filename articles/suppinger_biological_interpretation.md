# Suppinger single-cell biological interpretation

## Suppinger study biological description of cell types

The Suppinger dataset annotates gastruloid single cells into
developmental families spanning pluripotent and epiblast states,
gastrulation-associated progenitors, mesodermal and somitic lineages,
definitive endoderm, and rare culture-associated artefacts.
[Table 1](#tbl-suppinger-celltypes) summarises each annotated state and
its main biological interpretation in the gastruloid context.

| Developmental family | Cell type/state | Main biological interpretation |
|----|----|----|
| **Pluripotency and epiblast** | Naïve pluripotency | Ground-state, pre-implantation-like ESC identity; highly self-renewing and not yet lineage committed. |
|  | Exiting naïve pluripotency | Transition from naïve pluripotency toward a formative or post-implantation epiblast state, with increasing competence to respond to differentiation signals. |
|  | Epiblast | Post-implantation-like pluripotent state preceding gastrulation; the main Wnt-responsive substrate for primitive-streak induction. |
|  | Ectopic pluripotency | An abnormal gastruloid-core population that re-expresses naïve markers after Wnt stimulation. It is a culture-specific branch rather than a normal embryonic lineage. |
| **Gastrulation and axial progenitors** | Epiblast/primitive streak | Early transitional state entering gastrulation and acquiring mesendodermal competence. |
|  | Primitive streak | Gastrulation-associated progenitor population that generates mesoderm and definitive endoderm. |
|  | Caudal epiblast | Posteriorized epiblast associated with Wnt/FGF activity and continued production of axial and mesodermal progenitors. |
|  | Caudal epiblast/primitive streak | Posterior transitional population actively progressing from epiblast into primitive-streak-derived lineages. |
|  | Anterior primitive streak/definitive endoderm | Anterior streak-like population biased toward definitive endoderm and subsequently gut-like cells. |
|  | Neuromesodermal progenitors | Bipotent posterior progenitors capable of generating spinal neural and paraxial-mesodermal descendants; associated with continued axial elongation. |
| **Mesodermal and somitic differentiation** | Caudal mesoderm | Immature posterior mesoderm emerging from the caudal primitive-streak region. |
|  | Pre-somitic mesoderm | Unsegmented paraxial mesoderm containing the molecular programme that precedes somite formation. |
|  | Paraxial mesoderm | Trunk mesoderm progressing toward segmented somites and their musculoskeletal derivatives. |
|  | Somite differentiation front | Transition zone at which pre-somitic mesoderm becomes specified into new somite tissue. |
|  | Somite | Segmented paraxial mesoderm, representing a relatively mature trunk identity. |
|  | Hemogenic endothelium | Small endothelial-like branch with potential to generate hematopoietic progenitors. |
| **Endoderm** | Gut | Definitive-endoderm-derived gut-like lineage; usually a minority population in standard gastruloids. |
| **Culture-associated states** | Zscan4+ artefact | Rare Zscan4-high ESC-like state interpreted as culture- or stress-associated rather than part of the main developmental trajectory. |
|  | Cd63+ ectoderm-like artefact | Low-frequency culture-associated state that should not be interpreted as robust embryonic ectoderm without additional validation. |

and states
