# GastroDeconv2FateMap: Pseudo-Bulk Simulation and Deconvolution Benchmarking for Gastruloids

Utilities for aggregating single-cell profiles into pseudo-bulk samples,
annotating mouse genes, scoring deconvolution performance, and
benchmarking phenotype-guided algorithms on gastruloid differentiation
data.
