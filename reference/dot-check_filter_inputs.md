# Validate common gene-filter inputs

Validate common gene-filter inputs

## Usage

``` r
.check_filter_inputs(seurat_obj, meta_cols, assay, cell_mask = NULL)
```

## Arguments

- seurat_obj:

  A Seurat object.

- meta_cols:

  Required metadata columns.

- assay:

  Required assay name.

- cell_mask:

  Optional cell mask.

## Value

`NULL`, invisibly.
